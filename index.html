🔗 Google 試算表同步
填入以下資訊後，送貨記錄會即時同步到你的 Google 試算表。
📋 設定步驟
1
前往 sheets.new 建立新試算表，共用設為「知道連結的人可以編輯」
2
從網址複製試算表 ID：spreadsheets/d/[ID]/edit
3
前往 Google Cloud Console → 啟用 Sheets API → 建立 API 金鑰
4
填入上方欄位，按「儲存並測試連線」
⚠️ 注意
API 金鑰只存在瀏覽器本機，不會傳送到其他地方。試算表須設為可編輯才能寫入。
